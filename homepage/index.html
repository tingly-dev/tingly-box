How it works

From one laptop to a whole team, on one endpoint.

  1. 01 · Your agents

    Keep the tools you already use

    Claude Code, Codex, OpenCode, Cursor, Xcode, VS Code — or any app that speaks an OpenAI or Anthropic API.

  2. 02 · One endpoint

    Point them at Tingly Box

    One-click config writes the base URL and key for you: localhost:12580/tingly/<scenario>.

  3. 03 · Any provider

    Route to any model

    Rules map a model name to providers, with smart routing and fallback. Protocols are translated both ways, and OAuth lets you reuse existing quotas.

  4. 04 · Your team

    Hand out sharing keys

    Each member gets a dedicated key on a shared team endpoint. Model rules are managed centrally; data stays isolated per user.

  5. 05 · Power-ups

    Switch on more power

    Guardrails, MCP tools, Usage and Remote come built in. Turn on what you need, when you need it.

Any agent → any provider

Bring your own agent. Pick any model behind it.

Agents keep their native protocol. Tingly Box converts between Anthropic, OpenAI and Gemini formats, so Claude Code can run on DeepSeek and Codex can run on Claude.

Switch between profiles that map each task tier to a different model — Opus on one provider, Haiku on another.

API keys and OAuth

Add providers by key, or sign in with OAuth and reuse the quota you already pay for, in any compatible tool.

Smart routing

Route across models and tokens by cost, speed or your own policy, with load balancing and fallback built in.

Self-hosted models

vLLM, SGLang, Ollama, LM Studio, LocalAI and Jan connect like any cloud provider, with defaults pre-filled.

Image API

Route image generation and editing through the same gateway at /tingly/imagegen, with a built-in playground.

Team AI management

Give everyone AI. Keep one place to run it.

One team endpoint backed by centrally managed model rules. Members get their own keys; you get per-user usage, isolation and policy.

  1. 1

    Set the rules once

    Open Team and decide which models the team can call, and which providers serve them.

  2. 2

    Hand out sharing keys

    Create a key per member under Sharing Keys. Revoke or rotate one without touching anyone else.

  3. 3

    Track who uses what

    Dashboard → Team usage shows tokens, latency and cost estimates per member and per model.

    Quick start

    Running in a minute.

    macOS, Linux and Windows. Install from npm — the platform binary ships inside the package, so an npm mirror is all you need behind a firewall.

    # install (recommended)
npm install -g tingly-box@latest

tb start   # runs in the background (--no-daemon for foreground)
tb open    # opens the web UI

# update: reinstall, then restart
npm install -g tingly-box@latest && tb restart

# behind a firewall, any npm mirror works
npm install -g tingly-box@latest --registry=https://registry.npmmirror.com
    # one-off run without a global install
npx -y tingly-box@latest

# with a mirror
npx --registry=https://registry.npmmirror.com -y tingly-box@latest
    mkdir tingly-data
docker run -d --name tingly-box \
  -p 12580:12580 \
  -v "$(pwd)/tingly-data:/home/tingly/.tingly-box" \
  ghcr.io/tingly-dev/tingly-box
    # any OpenAI-compatible client works the same way
from openai import OpenAI

client = OpenAI(
    api_key="your-tingly-model-token",
    base_url="http://localhost:12580/tingly/openai/v1",
)
    # any Anthropic-compatible client works the same way
from anthropic import Anthropic

client = Anthropic(
    api_key="your-tingly-model-token",
    base_url="http://localhost:12580/tingly/anthropic",
)
    1. 1
