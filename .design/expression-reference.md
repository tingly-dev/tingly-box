# 表情参考(Expression Reference)

> 配套阅读:`reference-roles.md`(为什么是"参考图 + 用途",以及之前试过的路)。

## 是什么

参考图来源里和「浏览 / 粘贴 / 手绘」并列的第四个:**表情**。打开是一个动漫风格的
脸,选预设或调滑杆,确认后作为一张参考图加入,默认用途是「表情」。

只做动漫风,不求一个方案搞定全部:写实的参数化人脸要么许可不允许商用(FLAME),
要么是重资产管线;写实就用真照片 + 「表情」用途。

## 为什么是 VRM

- **开放标准,表情是标准的一部分**:每个 VRM 1.0 模型都有同一组预设
  (`happy angry sad relaxed surprised`、`blink*`、口型 `aa ih ou ee oh`、`look*`)。
  代码只用预设名(`expressionState.ts`),所以换一个模型不用改代码。
- 官方库 `@pixiv/three-vrm`,和人偶用的是同一个 three(0.170.0)。
- 示例模型 `VRM1_Constraint_Twist_Sample`(pixiv)的元数据许可:企业商用、修改、
  再分发都允许,不要求署名。出处记在 `frontend/public/assets/README.md`。

## 只留脸:裁剪既是体积,也是语义

`frontend/scripts/trim-vrm-face.mjs` 把模型裁到**只剩表情用得到的东西**:

| 留 | 删 |
|---|---|
| 被表情驱动的那块网格(脸,按 `morphTargetBinds` 认,不按名字) | 身体、衣服、鞋、**头发** |
| 表情用到的 14 个形变目标 | 其余 43 个 |
| 骨架、humanoid / lookAt / 表情定义、meta(含许可) | 缩略图、弹簧骨骼、节点约束 |

10.78 MB → **1.37 MB**。

删头发不只是省体积。头发、衣服、身体是"这个角色"的特征;带着它们的表情参考图,
等于邀请模型去抄一个没人要的角色——和人偶被读成身体、参考照片被抄走长相是同一个
问题。对照过四种(脸+头发 / 只有脸,各彩色 / 灰度):只有脸读起来就是"一张表情图";
灰度会把张开的嘴变成一团灰,所以留彩色。

取景同理:对准**五官**(下巴到眉毛占满),光头的头顶裁掉,既让表情是主体,也不给
模型一个"光头"去画。取景只在静止姿态量一次,换表情不会重新构图。

## 模型怎么加载

模型放在 `frontend/public/assets/expression/face.vrm`:构建时进 `dist/assets/`,
随前端嵌进后端二进制,由后端的 `/assets` 静态路由提供。**打开表情对话框时才下载**:
对话框是 `lazy()` 的,three-vrm 只在它的分块里(构建后检查过 `index.html` 的
`modulepreload` 里没有它)。加载失败允许重试。

## 两条通道

和骨架一样:**图给精确的脸,文字说它是什么**。提示词建议(不自动填)是
"图 N 是一张动漫风格的表情示意(只有脸):只让人物做出同样的表情——大笑,不要沿用
它的画风、脸型和配色"。预设直接叫名字;调过滑杆的按可见的部分描述
(`describeExpression`:开心、闭着眼、视线看向一侧……)。

## 交互

- 预设(11 个,缩略图就是这张脸在该表情下的样子)是主入口;滑杆收在「细调」里,
  默认折叠——大多数人要的是一个预设,九根滑杆摆在前面就成了整个对话框。
- 重新打开时,如果它不是任何预设(调过滑杆),细调自动展开。
- 缩略图右下角的按钮重新打开编辑,编辑后原位替换,保留用户设过的用途。
