# 图像素材库（Image Library）

> 状态：**前端原型，存储未接入**。素材存在模块内存里（`frontend/src/pages/image/library/assetStore.ts`），
> 用 mock 数据预置；刷新页面就会丢失。目标是把素材库落在图像输出目录上（见 §5）。

## 1. 为什么需要

在此之前，一张图只有三种下场：**正在用**（在参考图行、某个方案、历史里）、**是个文件**（输出目录，界面管不了）、
**删了**。缺一个"留着，但这会儿没在用"的地方：想留下的结果只能靠"历史还没被清掉"来保留，
删掉一个方案，它的参考图也就没了。

## 2. 和配置方案、历史的关系

```
素材库（留下来的）  ── 选用时拷一份 ──→  配置方案 / 本次请求
      ↑ 留下
历史（发生过的，可清空）
```

- **配置方案是工作上下文**：哪些图、哪些提示词、什么参数，用来完成一项工作。
- **素材库是收藏夹**：用户想留下的图和描述片段。
- **历史是发生过的事**，可以清空。

素材库和方案之间**不做交叉引用**：从素材库选图，就是把这张图拷一份进参考图行或方案；
素材库不记录"被哪些方案使用"，删除素材也不影响已经用上它的方案。先让大家用起来，
真有"改一处、处处更新"的需求时再考虑引用。

## 3. 规则

- **只有用户点「留下」才进库，没有隐式加入。** 大图预览里任意一张图（生成结果、导入的图、参考图）都可以留下。
  同一张图留两次不会重复。
- **能改的**：图片可以改名（详情标题处，和方案标题一样）；描述片段可以改名称和内容。
  图片本身不在素材库里编辑——选进参考图行，在 Playground 里改，满意了再留下。
- **描述片段按拷贝插入**，插进提示词后就是那条提示词自己的文字。
- **删除**：在详情里点删除，就地说明"会删除图片和文件，已经用在方案里的不受影响"，再确认一次。

## 4. 入口

- 侧栏 Image 下，分隔线之后：「素材库」。
- 参考图行的来源按钮：浏览 / 粘贴 / 手绘 / **素材库**。有图时四个按钮收窄，保持一行。
  从素材库选图可以多选，受参考图上限约束。
- 提示词框右侧：「插入描述片段」，插在光标处，必要时补一个逗号。菜单底部可以去管理片段。
- 大图预览：「留下到素材库」，已留下时显示对勾。

## 5. 这一版刻意不做的

被哪些方案使用、删除时级联、素材来源标签（生成 / 参考图）、尺寸和日期信息、选图时标记"已添加"。

## 6. 命名

中文叫「素材库」，片段叫「描述片段」：侧栏已经有一个顶级栏目「提示词」（编码 agent 的提示词和技能），
所以避免再出现一个"提示词"。英文为 Library / Snippets。

## 7. 接入时要补的

- 存储落在图像输出目录：生成结果在 `outputs/`，参考图在 `refs/`，片段可以是 `snippets/*.md`。
  这样"是个文件"和"被管理"是同一个状态。需要处理用户在外部删改文件的情况（扫描或文件监听）。
- 去重改为内容哈希，不再比较 data URL。
- 删除改为移入回收站。
- 历史里的生成结果可以考虑超期自动清理：有了「留下」，历史就可以放心地是临时的。
