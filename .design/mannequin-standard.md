# 人偶标准(Mannequin Standard)

> 配套阅读:`sketch-canvas.md` §4(人偶在产品里是什么)、`pose-from-image.md`
> (从照片导入)。这份文档只回答一件事:**人偶应该长成什么样,以及为什么**。
> 它是画法的**基准**——任何一次改人偶的形,先改这里,再改 `poseFigure.ts`。
>
> 唯一的事实源是 `frontend/src/utils/poseFigure.ts` 里的 `BONE` / `R` 两张表和
> `TORSO_PROFILE` / `HEAD_PROFILE`。下面的数值是它们的说明,不是它们的副本——
> 数字对不上时,以代码为准,并回来修这份文档。

---

## 0. 这份标准是怎么来的

前后返工了四轮,每一轮都是"我觉得这样好看"。第四轮的反馈是一句很准的话:
**"应该多看看行业里面大家是怎么做的,特别是美术相关的"**。去看之后,有两条
我自己拍脑袋定下的结论被直接推翻:

1. **关节应该收窄,不是鼓起来。**我一直在把球画得更好看,方向从一开始就错了。
2. **头不是太大,是太小。**上一轮我把头缩了一档,人直接变成 8.7 头身——那是
   时装插画的比例,不是人。

教训写在这里,而不是留在对话里:**对着参考图调参数是没有收敛点的,对着画法
的规矩调才有。**

---

## 1. 比例:Loomis 八头身

以头长为 1,从头顶往下数:

| 位置 | 头数 |
|------|------|
| 下巴 | 1 |
| 乳线 | 2 |
| 脐 | 3 |
| 耻骨(**正中**) | 4 |
| 膝 | 6 |
| 脚底 | 8 |

肩宽约 **2 个头**。这套是画人体的通用基准,不是风格选择:偏离它的人偶,
第一眼就会被读成"比例不对",而看的人往往说不清哪里不对。

实现上比例落在 `BONE`(骨长,任意单位、最后归一化)。检验方式是量出来的
头身比,而不是看着像不像——**人偶的比例是一个可测量的量**。

---

## 2. 形体:一个形,不是一堆体块

凸体块的并集永远会出卖接缝。躯干、头、四肢一律是**一条闭合轮廓**:

- **躯干** `TORSO_PROFILE`:肩宽 → 肋收 → 腰紧 → 胯展 → 臀收口。上缘挂肩线、
  下缘挂髋线,所以躯干会跟着肩胯拧转。**胯宽要从髋关节往外撑出来**(髋关节远在
  骨盆内部,是大腿的转轴,不是身体的边缘);照关节间距取宽度,人就成了一根筒。
- **头** `HEAD_PROFILE`:颅骨最宽(约 28% 处),经颧、下颌收到下巴。
- **四肢** `limbOutline`:沿节点角平分线两侧偏移 + 两端半圆帽。

厚度不是可选项:`chestDepth` / `pelvisDepth` 给出躯干在侧面的最小宽度,
否则一个转过身的人会变成一张纸。

---

## 3. 关节:收窄,不是鼓起

**这是整份标准里最重要的一条。**

实体木头人偶必须在关节处鼓出一个球,否则转不动——那是**制造工艺**。画画的人
(Proko 那一派的"mannequinization")在关节处是**收窄**的:关节是骨头交汇处、是
一个转面,不是肉最多的地方。照着制造工艺画,就是人偶读起来像玩具的全部原因。

半径表(占身高比例,`R`):

| 节点 | 半径 | 规矩 |
|------|------|------|
| 上臂 | 0.031 | 上臂**几乎不收**,从上到下差不多粗 |
| 肘 | 0.028 | 比上臂略窄 |
| 腕 | 0.019 | |
| 大腿 | 0.043 | |
| 膝 | 0.030 | **掐进去** |
| 腓肠 | 0.034 | 小腿**最粗处在膝下三分之一**,不是从膝往下直接收 |
| 踝 | 0.023 | |
| 髋球 | 0.031 | 唯一保留的球,属于骨盆 |

转折只用一条**横过肢体的细弧线**(seam)交代:那是一个转面,不是一个圆点。
一个完整的圆会被读成画在胳膊上的一个点。

手和脚是肢体的**末端**(接在腕/踝之后的两个节点),不是贴上去的锭子。手比腕
只宽一点点就够读成手;明显更宽就成了烤箱手套。

---

## 4. 脖子向前 7°

`NECK_FORWARD = 7`。垂直的脖子是一根桅杆,人的颈椎从来不垂直。这一条便宜到
几乎不要钱,但它是"这个人偶像个人"和"像个衣架"的差别之一。

---

## 5. 折回去的肢体拆成两片

盘腿俯视时小腿掖在大腿下面,肢体在**屏幕上**折回了自己身上,单条轮廓会自交、
填出一片鳍。这时在折点把肢体拆成两片、按深度排序——画画的人在这里也是把小臂
画在**上臂之上**,而不是把两者揉成一个形。

阈值取**屏幕上的转角**(`FOLD_LIMIT`,约 110° 偏离笔直),不是关节的真实角度:
正面看直挺挺的膝盖可以在三维里弯得很厉害。

---

## 6. 上色:三档中性灰

躯干 / 髋球更深 / 头更浅。**不用木色**——木色只会邀请模型画一个木头娃娃。
面部平面比头**略亮**:光在前方,脸是头上最迎光的一面;一块深色斑会被画成面具。

每个**体块**一盏灯,不是每个零件一盏灯。躯干整条轮廓吃同一道光,四肢逐段横向
打光(一段肢体本来就是一根圆柱)。rim **每组一遍**,不是整个人偶一遍。

---

## 7. 改这份标准的规矩

1. 先改这份文档,说清楚**依据是什么**(某条画法的规矩、某个可测量的比例),
   再改代码。"我觉得好看"不是依据。
2. 改完**放大了看**。难看的东西只在放大后才明显,缩略图会替你遮丑——髋球画两遍
   那个 bug 藏了整整一版。
3. 全库 36 个预设 + 6 个视角一起看(`poseFigure.test.ts` 之外还有对照表):
   一个姿势好看不算数,**一张对照表上一眼看出来的问题才是真问题**。
