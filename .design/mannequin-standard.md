# 人偶标准(Mannequin Standard)

> 配套阅读:`sketch-canvas.md` §4(人偶在产品里是什么)、`pose-from-image.md`
> (从照片导入)。这份文档只回答一件事:**人偶应该长成什么样,以及为什么**。
> 它是画法的**基准**——任何一次改人偶的形,先改这里,再改 `poseFigure.ts`。
>
> 唯一的事实源是 `frontend/src/utils/poseFigure.ts` 里的 `BONE` / `R` 两张表和
> `CHEST_PROFILE` / `PELVIS_PROFILE` / `HEAD_PROFILE`。下面的数值是它们的说明,不是副本——
> 数字对不上时,以代码为准,并回来修这份文档。

---

## 0. 这份标准是怎么来的

前后返工了四轮,每一轮都是"我觉得这样好看"。第四轮的反馈是一句很准的话:
**"应该多看看行业里面大家是怎么做的,特别是美术相关的"**。去看之后,有两条
我自己拍脑袋定下的结论被直接推翻:

1. **关节应该收窄,不是鼓起来。**我一直在把球画得更好看,方向从一开始就错了。
2. **头不是太大,是太小。**上一轮我把头缩了一档,人直接变成 8.7 头身——那是
   时装插画的比例,不是人。

教训写在这里,而不是留在对话里:**对着参考图调参数是没有收敛点的,对着画法
的规矩调才有。**

---

## 1. 比例:Loomis 八头身

以头长为 1,从头顶往下数:

| 位置 | 头数 |
|------|------|
| 下巴 | 1 |
| 乳线 | 2 |
| 脐 | 3 |
| 耻骨(**正中**) | 4 |
| 膝 | 6 |
| 脚底 | 8 |

肩宽约 **2 个头**,胯宽约肩宽的 **3/4**(约 1.5 个头)。这套是画人体的通用基准,
不是风格选择:偏离它的人偶,第一眼就会被读成"比例不对",而看的人往往说不清
哪里不对。

实现上比例落在 `BONE`(骨长,任意单位、最后归一化)。检验方式是量出来的
头身比,而不是看着像不像——**人偶的比例是一个可测量的量**。

---

## 2. 形体:躯干两块,其余各一条轮廓

**躯干这一条改过三次,三次的位置都不同,值得把过程留下来:**

1. **三个凸体块**(胸椭圆 + 腰球 + 骨盆椭圆),每块各自打光 → 读成"三个蛋摞着"。
   凸体块的并集永远会出卖接缝。
2. **一条闭合轮廓**,腰上画一条细线 → 形是整的,但腰**读不出来**:一条画在形体上的
   线是一道折痕,不是一个关节。
3. **两块 + 中间露出腰球**(现在)→ 这才是艺用木偶的躯干,也是腰真正读得出来的唯一
   办法。

第 2 步不是白走的:它证明了"体块并集出卖接缝"这条教训的适用范围——**问题不在于分块,
在于分成的是不是有轮廓的形**。三个蛋是三个蛋;一个胸廓盾形 + 一个骨盆桶,各自是有
侧面轮廓的形体,拼起来是一个木偶。

现在:

- **胸块** `CHEST_PROFILE`:斜方肌 → 肩角 → 肋收 → 腰(块在这里结束)。
- **骨盆块** `PELVIS_PROFILE`:窄口 → 髂嵴(最宽)→ 收到髋关节收口。
- **中间是真的空隙**,腰球从里面露出来。空隙必须是真的:两块不能相接,相接就又变回
  一条折痕。
- 头、四肢仍然各是一条闭合轮廓。

两块的宽度都**比它挂着的关节窄**,所以球在角上支出来,肢体**搭在边缘上**(§2.6)。
- **头** `HEAD_PROFILE`:颅骨最宽(约 28% 处),经颧、下颌收到下巴。
- **四肢** `limbOutline`:沿节点角平分线两侧偏移 + 两端半圆帽。

厚度不是可选项:`chestDepth` / `pelvisDepth` 给出躯干在侧面的最小宽度,
否则一个转过身的人会变成一张纸。

## 2.5 关节的位置 = 身体的角(返工过一次)

**这条比上面任何一条都更容易毁掉一堆姿势,而且很难一眼看出是它的锅。**

出过的 bug:为了修"躯干像根筒",我把躯干宽度**从关节那里撑开**(肩 ×1.29、
胯 ×1.52 还加了个 pad)。结果身体的边缘跑到关节外面去了——

- 肩关节在三角肌**里面**,手臂成了从一个"肩台"底下挂出来的东西,一抬手就出现
  一个怪缺口;
- 髋关节挤在中间,骨盆往两边撑、还垂到关节**下面**,腿从一条"裙子"中间的缝里
  伸出来。正面看就是一条**尿布**。

正确的关系是反过来的:

> **肩关节就在三角肌的外角上,髋关节就在骨盆的下外角上。**
> 木头人偶上,球**就是**那个角;肢体是从角上转出来的,不是从板子中间钻出来的。

所以躯干的宽度不是"从关节撑开多少",而是"关节要放在身体的角上"——撑不够就
**把关节挪出去**(改 `BONE.shoulderSpan` / `hipSpan`),不是把身体吹大。

落到数上(占身高):

| | 关节半跨 | 身体半宽 | 关节在身体宽度的 |
|---|---|---|---|
| 肩 | 0.118 | 0.136(= 2 个头) | 87% |
| 胯 | 0.070 | 0.102(= 1.5 个头) | 75%(在关节那一层量) |

还有一条同样重要:**骨盆到髋关节就结束,不往下垂。**骨盆是一个向下收的梯形,
最宽处在髂嵴(关节**上方**),然后收到关节那一层收口。多垂出去的那一截就是尿布。

可测量,所以有测试守着(`hangs each limb off the body's corner…`):出事之前那一版
量出来是肩 0.77、胯 0.63,骨盆垂在关节下面 6.5% 身高。

## 2.6 手臂搭在边上,不是嵌进身体里

木偶上,肩球从胸块的角上**支出来**,上臂贴着球的**外侧面**挂下去。整条手臂在胸块的
轮廓之外,只在肩角那里搭着一点。

我做错过两次,方向相反:

- 先是把手臂的根往躯干里塞了 0.78 个半径(为了消掉肩线上的一个圆包),于是手臂是从
  躯干**里面**长出来的;
- 然后把胸块压窄到 0.80,想让手臂露在外面,结果胸块成了一块**薄板**,肩球整个浮在
  外面像两块护肩。

对的做法是两边一起动:

| | 值 | 意思 |
|---|---|---|
| `CHEST_REACH` | 0.92 | 胸块的角走到肩关节的 92%——球支出来,但大部分压在块上 |
| 手臂根外移 | 0.75 × 肩球半径 | 上臂从**球的外侧面**起步,不是从关节中心 |
| 手臂根内收 | 0.18 × 上臂半径 | 只够把端帽藏进肩角,不再是往身体里塞 |

腿不用这一套:大腿本来就是从骨盆**底下**出来的。

## 3. 关节:球窝有球,铰链收窄

**这是整份标准里最重要的一条,而且它返工过两次,两次方向相反。**

第一版:每个关节一个球(肩、肘、腕、髋、膝、踝),照着实体木头人偶抄。读起来像玩具。

第二版:**全部去掉**,理由是"实体人偶在关节处鼓起是为了能转,那是制造工艺不是形体;
画画的人在关节处是收窄的"。这条理由本身没错,但**推得太远了**。

现在:**看真的木头人偶,它自己就给出了分界线**——

| 关节 | 人偶上是什么 | 我们怎么画 |
|------|--------------|------------|
| 肩、髋 | 明显的**球**(球窝关节,球就是关节本身) | 球,画在躯干**下面**,只露出肢体没盖住的那一牙 |
| 肘、膝、腕、踝 | **收窄**,一根销钉——上臂往下收到肘,小臂从肘再往下收到腕 | 肢体轮廓自己的收窄 + 一条横过肢体的细弧线 |

所以"关节处收窄"这条规矩是对**铰链**说的,不是对**球窝**说的。把球抄到铰链上,人偶
读成玩具;把球从球窝上也拿掉,肩膀就没有了转轴,手臂像是从躯干侧面长出来的。

半径表(占身高比例,`R`):

| 节点 | 半径 | 规矩 |
|------|------|------|
| 上臂 | 0.031 | 上臂**几乎不收**,从上到下差不多粗 |
| 肘 | 0.028 | 比上臂略窄 |
| 腕 | 0.019 | |
| 大腿 | 0.043 | |
| 膝 | 0.030 | **掐进去** |
| 腓肠 | 0.034 | 小腿**最粗处在膝下三分之一**,不是从膝往下直接收 |
| 踝 | 0.023 | |
| 髋球 | 0.031 | 球窝,属于骨盆 |
| 肩球 | 0.034 | 球窝,属于躯干 |

铰链的转折只用一条**横过肢体的细弧线**(seam)交代:那是一个转面,不是一个圆点。
一个完整的圆会被读成画在胳膊上的一个点。躯干在腰上也有这么一条——木头人偶那里是
胸块和骨盆块之间真实的一道缝,一条闭合轮廓上就是同一件事的画法。

手和脚是肢体的**末端**(接在腕/踝之后的两个节点),不是贴上去的锭子。手比腕
只宽一点点就够读成手;明显更宽就成了烤箱手套。

## 4. 脖子向前 7°

`NECK_FORWARD = 7`。垂直的脖子是一根桅杆,人的颈椎从来不垂直。这一条便宜到
几乎不要钱,但它是"这个人偶像个人"和"像个衣架"的差别之一。

---

## 5. 折回去的肢体拆成两片

盘腿俯视时小腿掖在大腿下面,肢体在**屏幕上**折回了自己身上,单条轮廓会自交、
填出一片鳍。这时在折点把肢体拆成两片、按深度排序——画画的人在这里也是把小臂
画在**上臂之上**,而不是把两者揉成一个形。

阈值取**屏幕上的转角**(`FOLD_LIMIT`,约 110° 偏离笔直),不是关节的真实角度:
正面看直挺挺的膝盖可以在三维里弯得很厉害。

---

## 6. 上色:三档中性灰

躯干 / 球窝更深 / 头更浅。**不用木色**——木色只会邀请模型画一个木头娃娃。
面部平面比头**略亮**:光在前方,脸是头上最迎光的一面;一块深色斑会被画成面具。

每个**体块**一盏灯,不是每个零件一盏灯。躯干整条轮廓吃同一道光,四肢逐段横向
打光(一段肢体本来就是一根圆柱)。rim **每组一遍**,不是整个人偶一遍。

---

## 7. 改这份标准的规矩

1. 先改这份文档,说清楚**依据是什么**(某条画法的规矩、某个可测量的比例),
   再改代码。"我觉得好看"不是依据。
2. 改完**放大了看**。难看的东西只在放大后才明显,缩略图会替你遮丑——髋球画两遍
   那个 bug 藏了整整一版。
3. 全库 36 个预设 + 6 个视角一起看(`poseFigure.test.ts` 之外还有对照表):
   一个姿势好看不算数,**一张对照表上一眼看出来的问题才是真问题**。
4. **改宽度之前,先把每条轮廓描成不同颜色看一眼。**"肩球浮在外面"这个 bug 在灰度
   图上看着像是"渲染有点怪",把胸块描成红色、手臂描成绿色之后一秒就定位了。猜三次
   不如描一次。
