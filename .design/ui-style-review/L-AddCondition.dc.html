8 · 合并后，新增条件怎么做才优雅
难点：一个条件由"看什么 + 怎么比 + 比什么值 + 命中后去哪"四件事组成，今天靠一个弹窗逐项填。目标是：不开弹窗，不先切模式，每一步都在规则列表里原地完成，并且在没有条件时也能被发现。
下面是同一个动作的四个状态，由上到下依次发生。

  • 起手式来自真实的条件类型：长对话（Token ≥）、Claude Code 子代理（agent.claude_code）、开启 Thinking、特定时段（time），都是现有 position，不是新概念。

  • 点击一个起手式，直接进入第③步，新行已带好默认值。

  • 还要定的

    3. 起手式的默认阈值（如 60,000 token）是否应由后端给出。
