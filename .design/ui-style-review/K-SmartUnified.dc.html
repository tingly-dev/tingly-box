7 · Smart 与 Direct 合成一套规则
视觉语言完全沿用现在的卡片、节点盒子和协议标记，只改结构：去掉 Direct/Smart 切换，规则永远是一列有序的"条件 → 目标"，末尾固定一行"否则"。只有这一行时就是今天的 Direct。
现状 · Smart 真实截图（Claude Code 页的规则卡）
  • 两套目标语法：条件行是一排平铺的服务，Default 行是 T0/T1/T2 分层。
  • Default 游离：和条件行隔着一块空白，不像"否则"。
  • 右侧被裁：服务多了，Add model 和 T0/T2 行被截断。
  • "Unconditional, ignore"：第 4 条像个错误，没有说明。
  • 切换 Direct 时，上面的条件整体消失，配置却隐形保留。

要先确认的事
1. 后端：条件行的目标能否也使用分层（T1/T2 兜底）？若不能，条件行只画 T0，并在 Otherwise 行才出现 then。
2. 已有规则迁移：Direct 规则映射为"只有 Otherwise"，Smart 规则映射为"条件 + Otherwise"，无需数据迁移，只是 UI。
3. 引导和文案：现有的 Direct/Smart 教学弹窗要改写。
