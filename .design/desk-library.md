# Desk 提示词库（Library）

> 状态：**设计稿，未实现**。前置阅读：`desk.md`、`image-library.md`（本功能照搬它的「描述片段」）。

## 1. 是什么

Desk 里存一批常用提示词，点一下就发出去开工。类似镜像库：挑一个，直接跑。
重点不是 chat，而是**库**；chat 是开工之后的事。

不涉及 profile、权限、模型：这些沿用任务表单现在的默认，库完全不碰。

## 2. 一条什么样

和图像库的 `PromptSnippet` 一样，只有名称和内容：

```ts
interface PromptSnippet { id: string; name: string; text: string; createdAt: number }
```

## 3. 交互

- **入口**：没有选中 session 时，主区直接显示提示词库（卡片：名称 + 内容前两行，等宽字体）。
- **运行**：点卡片上的「运行」，用顶部选中的目录 + 这段提示词创建 session，直接跳进去。
  调用的就是任务表单现有的创建函数，后端不改。
- **先改再发**：卡片上的「填入」把内容放进任务表单的提示词框，用户改完自己发。
- **目录**：卡片不绑定目录。库顶部有一个目录选择，默认当前项目 / 最近目录；没选目录时「运行」置灰。
- **留下来**：只有用户主动才进库——库里「新建」，或任务表单里「存入库」。可改名、改内容、删除；
  删除不影响已经开出的 session。
- **内置几条**，首次打开就不是空的（可复制后改，本身只读）：
  review 当前改动、跑测试并修复、解释这个仓库、写 commit message。

## 4. 存储

先放浏览器本地（和 Desk 的项目快捷方式一样），用 `snippetStore` 包一层，以后换后端只换这一层。
参考图像库：`frontend/src/pages/image/library/assetStore.ts`。

## 5. 命名

中文「提示词库」，条目叫「提示词」；英文 Library / Prompt。
不叫「任务」（和后台任务撞），不叫「命令」（和 slash command 撞）。

## 6. 这一版不做

变量/参数、分组、搜索、导入导出、绑定目录/profile/权限、批量运行。
下一步最自然的是提示词里的单行变量（如 `{{branch}}`）。
