0 · Projects 的气质
沿用 Tingly Box 的主题和组件，但 Projects 自己是什么样，先在这里定下来。
用户打开 Projects 时在问
什么在等我？
琥珀点 + 「等你处理」排在最前
什么在跑？
中性转圈，数量写在行尾
什么好了可以看？
「Review changes」是该区域唯一的蓝按钮
哪里出错了？
红点 + 一句原因
所以界面遵守四条
1. 安静的工作台
Projects 是人和一群 agent 并行干活的地方，用户是来「接手」的，不是来看热闹的。界面默认安静：中性灰为底，让标题、对话、diff 当主角。
2. 颜色只留给「需要你」和「出错」
全页只有两种提示色：琥珀 = 卡在你这里，红 = 出错了。运行中、已完成、已合并都是中性色，靠动效和文字区分，不靠色相。
3. 品牌蓝只做两件事
选中项，和每块区域里唯一的主操作（Review changes / Allow）。蓝不再代表状态。
4. 同一件事，只有一种长相
同一个状态在侧栏、列表、卡片、头部、任务里用同一个标记、同一个词、同一个位置。
